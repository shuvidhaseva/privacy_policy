Privacy Policy - Rozkhata

Last Updated:

Humari Rozkhata app par aapka swagat hai. Aapka privacy aur data ki suraksha humare liye bohot mahatvapurna hai. Yeh Privacy Policy batati hai ki jab aap Rozkhata app ka istemal karte hain, toh hum aapke data ko kaise collect, use, aur protect karte hain.

1. Data Collection (Aapka Data)

Rozkhata app mukhya roop se aapke daily transactions, khata records, aur hisab-kitab ko manage karne ke liye banayi gayi hai.

  • Local Storage: Aapka sara hisab-kitab data (Jaise customer name, transaction amount, dates) aapke device ke local storage mein save hota hai.
  • Personal Information: Hum aapka koi bhi sensitive personal data (Jaise bank account passwords, UPI PINs) collect nahi karte.
2. Data Storage and Security
  • Aapka transaction data aapke phone/device par hi rehta hai jab tak aap ise backup na karein.
  • Hum aapke khate ke data ko kisi teesre (third-party) server par bina aapki anumati ke sell ya share nahi karte.
3. App Permissions

App ki behtar service ke liye hum aap se kuch basic permissions maang sakte hain:

  • Storage Permission: Transaction reports (PDF/Excel) ya backup file save karne ke liye.
  • Contacts Permission (Optional): Khata mein naye customer ka naam aur number aasani se add karne ke liye.
4. Third-Party Services

App mein crash reporting ya analytics ke liye hum standard third-party tools (Jaise Google Firebase ya Google Analytics) ka use kar sakte hain, taaki hum app performance ko behtar bana sakein. Ye tools non-personal device information collect karte hain.

5. Changes to This Policy

Hum samay-samay par apni Privacy Policy ko update kar sakte hain. Kisi bhi badlav ki jankari aapko is page par update karke di jayegi.
